# 猜数字小游戏

一个用 Python 编写的单文件命令行小游戏：电脑随机想一个 1~100 的整数，你来把它猜出来！

## 游戏规则

1. 电脑随机生成一个 **1-100** 之间的整数作为答案
2. 玩家输入自己猜的数字
3. 程序提示 **"大了"** 或 **"小了"**，引导你逐步逼近答案
4. 猜中后显示本局总猜测次数
5. 一局结束后可以选择是否再来一局

## 运行环境

- Python 3.6 及以上版本（无需安装任何第三方库）

## 如何运行

```bash
# 进入项目文件夹后执行
python guess_number.py
```

也可以在命令提示符（Win + R → 输入 cmd）中 cd 到本文件夹再运行上面的命令。

## 项目结构

猜数字/

```

## 代码逻辑简述

- `play_once()`：负责一局游戏的完整流程 —— 生成随机答案、循环读取输入、校验合法性、比较大小并计数
- `main()`：主流程控制，一局结束后询问是否再来一局
- 输入校验：非整数或超出 1-100 范围的输入会被提示重新输入，不计入猜测次数

## 示例运行

```
